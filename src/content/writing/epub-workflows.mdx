EPUB Toolkit combines several volumes into one collection while preserving text, illustrations, and chapter structure. Its public web application performs the work on your device.

## Start with the reading order

Add the volumes and arrange them in the order you want to read. The queue shows whether each file is ready. Give the collection a title and choose how its table of contents should be organized.

## Inspect before keeping

Use the contents preview to check the collection, then download the merged EPUB. The Inspect tool exposes metadata and archive structure. The Split tool can recover volumes from a collection previously merged with the toolkit.

## Use the public application

[Open EPUB Toolkit](https://yumizhi.github.io/lightweight_epub_merge_tool/) or read its [source and documentation](https://github.com/yumizhi/lightweight_epub_merge_tool). Python and Node command-line workflows are also documented in the repository.
