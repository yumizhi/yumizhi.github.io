## Research artwork derived from stored runs

Generated by `npm run art` (`scripts/build-research-art.mjs`, then `scripts/build-og.mjs` for the Open Graph cards
`public/images/og.png` and `og-tide.png`) from the files in `public/media/tide/sampling/`
(one Stable Diffusion 2.1 run, seed 42, 50 steps, injection at step 35; frames are VAE-decoded
clean-image estimates). Nothing in this table is synthesised by an image model.

| Output | Built from | Used in |
| --- | --- | --- |
| `public/images/art/tide-banner.webp` | One vertical strip from each of the 50 TIDE frames | Homepage plate, TIDE banner, research index |
| `public/images/art/tide-lane-{original,tree,tide}.webp` | Every fifth frame of each run | Homepage TIDE card |
| `public/images/art/tide-sprite-{original,tree,tide}.webp` | All 50 frames of each run in a 10 × 5 sheet | Trajectory explorer, homepage lens |
| `src/data/tide-drift.json` | Mean absolute RGB difference from the unwatermarked frame at the same step | Trajectory explorer chart. A measurement of this one run, not a paper metric. |
| `src/data/tide-guidance.json` | Scalars from `guidance-trace.json` (budget split, overlap, curvature) | Trajectory explorer and guidance diagram |

| Asset | Source | Handling |

## Known gaps

- No talk slides, posters or code releases have been supplied for any of the three papers.
- TIDE per-attack numbers for Tree-Ring and ROBIN appear only as bar charts in the paper, so the site
  shows their averages from Table 1 and per-attack values for TIDE and its ablations only.
- The SASBO and meta-learning papers have no stored experiment output; their interactive figures are
  either table data or conceptual.
- No personal photograph has been supplied; the existing avatar is used.
